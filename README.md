# 🐧 Linux Fundamentals

## About This Project
This project contains my learning notes about Linux commands, file management, user management, and basic system administration.

## 1. What is Linux?
Linux is an open-source operating system widely used in servers, networking, and IT infrastructure.

## 2. Basic Linux Commands

| Command | Purpose |
|---|---|
| `pwd` | Shows current directory |
| `ls` | Lists files and folders |
| `cd` | Changes directory |
| `mkdir` | Creates a directory |
| `touch` | Creates an empty file |
| `cp` | Copies files |
| `mv` | Moves or renames files |
| `rm` | Removes files |
| `clear` | Clears terminal screen |

## 3. System Information Commands
- `uname -a` – Displays system information
- `whoami` – Shows current username
- `date` – Displays date and time
- `df -h` – Shows disk space
- `free -h` – Displays memory usage

## 4. Networking Commands
- `ip addr` – Displays IP addresses
- `ping` – Tests network connectivity
- `hostname` – Displays computer name
- `ip route` – Displays routing information
- `ss -tuln` – Displays listening network sockets

## 5. User Management
- `whoami` – Check current user
- `id` – Display user and group IDs
- `sudo` – Execute commands with elevated privileges
- `passwd` – Change a user's password

## 6. File Permissions
Linux uses three main permission types:
- Read (r)
- Write (w)
- Execute (x)
